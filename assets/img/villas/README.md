# Fotografias de las villas

Una carpeta por villa, con su referencia en minusculas:

```
assets/img/villas/s023/01.jpg 02.jpg 03.jpg 04.jpg 05.jpg
assets/img/villas/s024/...
assets/img/villas/s025/...
assets/img/villas/s026/...
```

Nombres sin espacios ni acentos. JPG o WEBP. Cuanto mas grandes mejor:
se optimizan al integrarlas.

**Los dossiers PDF no van aqui.** Este repositorio es publico —de el se sirve
la web— asi que cualquier archivo subido queda accesible. Los dossiers llevan
precio y datos del vendedor, y se pasan por chat, no por el repositorio.
